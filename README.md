# DailyFlow
TaskPulse é uma aplicação de gerenciamento de tarefas focada em produtividade. O projeto permite criar, editar, concluir e excluir tarefas, definir prioridades, status e prazos, além de armazenar os dados com PostgreSQL. Desenvolvido com React, Node.js, TypeScript, Prisma e, futuramente, Python para análise de produtividade.
